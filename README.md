# Portfólio | Jessica Silva

Portfólio animado em HTML, CSS e JavaScript puros, em português e inglês.

## Estrutura

```
portfolio/
├── index.html      # conteúdo da página
├── css/style.css   # estilos, cores e animações
├── js/script.js    # links, foto, idioma PT/EN e animações
└── images/foto.jpg # foto de perfil
```

## Como usar

Abra `index.html` no navegador ou use a extensão Live Server no VS Code.

## Como editar

- Textos: `index.html` (o inglês fica no atributo `data-en` de cada elemento).
- Cores: variáveis no início de `css/style.css`.
- Links e foto: início de `js/script.js`.
